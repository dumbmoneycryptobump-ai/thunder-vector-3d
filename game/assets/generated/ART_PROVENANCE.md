# Thunder Vector 3D — Generated Art Provenance

- Generated: 2026-08-29
- Tool mode: built-in OpenAI ImageGen (`image_gen`), new-image generation
- Integration: transparent `Sprite3D` overlays on original procedural 3D hulls
- Runtime: all assets are local; no network or AI service is used by the game
- Source size: 1254 × 1254 RGBA PNG
- Verification: `res://tests/art_integration_test.gd` checks alpha mode, transparent corners, border samples, imported textures, Node3D parents, art roles, and GL Compatibility
