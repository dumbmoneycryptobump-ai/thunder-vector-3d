# Thunder Vector 3D v1.1.0

[直接在瀏覽器遊玩](https://dumbmoneycryptobump-ai.github.io/thunder-vector-3d/index.html) · [MIT 原始碼](https://github.com/dumbmoneycryptobump-ai/thunder-vector-3d) · [v1.1.0 下載](https://github.com/dumbmoneycryptobump-ai/thunder-vector-3d/releases/tag/v1.1.0)

Windows 玩家下載 `ThunderVector3D-1.1.0-windows-x86_64.zip`，解壓後開啟 `ThunderVector3D.exe`，不需安裝 Godot。手機、平板與其他桌面系統使用上方網頁；第一次載入需下載遊戲資料，顯示「離線快取已完成」後可離線重開。

保留三戰區、導彈、連鎖閃電、貫穿雷射、百發超載與 2–4 架僚機。鍵盤／滑鼠、多指移動與射擊、手把按鍵共用玩法。網頁按「開始遊戲」啟動；切換分頁後會暫停，返回需繼續。

正式 Pages 已實際啟動並通過四種 Chrome 螢幕尺寸、武器切換、多指獨立釋放／取消、設定與斷網重載檢查。實體 Android／iPhone、macOS／Linux、實體手把類比軸與另一台乾淨 Windows 尚未實測。需要 WebGL 2／WebAssembly；不保證舊機或所有硬體效能。Windows EXE 未簽章，不建議關閉系統安全防護。

`ThunderVector3D-web.zip` 是可自行部署的完整網站包，需 HTTPS 或 localhost HTTP 服務，不是直接雙擊 HTML。
