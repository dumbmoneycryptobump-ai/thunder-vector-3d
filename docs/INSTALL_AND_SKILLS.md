# 安裝程式與技能規劃

## 階段 A：當天可玩
- 安裝 Godot、Git、Node、Codex。
- 匯入 `game`，確認移動、射擊、死亡與重開。
- 學會 Scene、Node、Inspector、Output、Debugger。

## 階段 B：一週內可修改
- GDScript 基本語法與 Node 生命週期。
- 讀懂 `main.gd` 中玩家、敵人、子彈、UI 與 BOSS 區段。
- 每次只改一個數值或一個行為；用 Git 提交。

## 階段 C：兩到四週可擴充
- 抽出 Player、Enemy、Projectile、HUD 模組。
- 建立物件池與測試場景。
- Blender 製作低面數 GLB；Godot 匯入並替換佔位模型。
- 建立設定、存檔、關卡表與多階段 BOSS。

## 階段 D：發佈
- Godot Profiler 與 GPU／CPU 瓶頸。
- Windows Export Templates、版本、圖示與乾淨機器測試。
- 素材授權清單、錯誤日誌與版本更新流程。
